# AI OS Job Portal

This project is a foundation for a powerful job portal that can aggregate jobs from multiple public sources, normalize them, deduplicate them, and publish them through a searchable website.

## Current Architecture

- `job-scraper-test/server` serves the website and JSON API.
- `job-scraper-test/src/scrapers` contains source-specific scraping agents.
- `job-scraper-test/output/jobs.json` is the local job store generated by the scrapers.
- `.agents`, `.claude`, and `.cursor` are preserved agent skill lanes for future automation work.

## Run

```bash
npm run dev
```

Open `http://localhost:4173`.

## Scrape Jobs

```bash
npm run scrape
```

The scraper is intentionally modular: add new sources in `job-scraper-test/src/scrapers/adapters.js` and keep normalization/deduplication shared.

## Notes

Use official APIs, RSS feeds, sitemaps, and permitted endpoints wherever possible. For direct website crawling, add source-specific rate limits and respect each site's terms and robots rules.
